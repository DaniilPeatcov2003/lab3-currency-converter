# Валютный конвертер

Простое веб-приложение для конвертации сумм по последним опубликованным курсам Frankfurter
(данные Европейского центрального банка). Курсы обновляются по рабочим дням. Успешные ответы
сохраняются локально; при отсутствии сети приложение использует последний сохранённый курс и
показывает его дату.

## Запуск

Из корня репозитория перейдите в каталог приложения и запустите локальный сервер:

```powershell
Set-Location .\lab3-currency-converter
python -m http.server 8000
```

Откройте приложение по адресу <http://localhost:8000/src/>. Для получения нового курса требуется
подключение к интернету; сохранённые курсы доступны офлайн.

## Тесты

Требуется Node.js 20 или новее. Запустите из каталога приложения одной командой:

```powershell
npm test
```

Для просмотра отчёта тестов в браузере запустите локальный сервер и откройте
<http://localhost:8000/tests/test-runner.html>.
